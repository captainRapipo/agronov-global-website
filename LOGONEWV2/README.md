# AGRONOV GLOBAL — Globe Logo (V2)

Brand-gradient wireframe globe with **AGRONOV** arced over the top and **GLOBAL** along
the bottom. Uses the exact site gradient and the signature orange accent dot.

## Brand values
| Token   | Hex       | Use |
|---------|-----------|-----|
| blue    | `#4f74d6` | gradient top |
| purple  | `#9a4fd0` | gradient upper-mid |
| pink    | `#ff6f91` | gradient lower-mid |
| orange  | `#ffb347` | gradient bottom |
| dot     | `#ff9900` | accent marker |
| font    | Plus Jakarta Sans 800 | embedded in every SVG |

## Files

**Masters (SVG, scalable, font embedded — self-contained):**
- `agronov-globe-icon.svg` — square badge on deep-indigo background (app icon / avatar)
- `agronov-globe-transparent.svg` — same badge, no background (white text — for dark surfaces)
- `agronov-globe-mark.svg` — globe only, no text (small sizes / favicon)
- `agronov-globe-lockup.svg` — globe + wordmark, horizontal (for light backgrounds)
- `agronov-globe-lockup-dark.svg` — horizontal lockup with white wordmark (for dark backgrounds)

**Rendered PNGs:**
- Icon: `...-icon-512 / 1024 / 4096.png`
- Transparent badge: `...-transparent-512 / 1024 / 4096.png`
- Mark: `...-mark-32 / 180 / 512 / 4096.png`
- Lockup: `...-lockup-1600 / 3200.png`, `...-lockup-dark-1600.png`

## Notes
- SVGs are the source of truth — re-render PNGs from them at any size.
- The orange dot is a subtle brand tie; remove the `dot` circle in the SVG to go fully clean.
